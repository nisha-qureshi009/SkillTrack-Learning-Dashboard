# SkillTrack — Learning & Productivity Dashboard

A responsive beginner-friendly web development project built with **HTML5, CSS3 and vanilla JavaScript**.

## Features

- Overview dashboard with live statistics
- Create, update and delete learning goals
- Track goal progress from 0–100%
- Add, complete, filter and delete daily tasks
- Clear completed tasks
- Automatic progress calculations
- Dark and light theme toggle
- LocalStorage persistence (data stays in the same browser)
- Responsive layout for desktop, tablet and mobile
- Accessible labels and semantic HTML

## Run locally

1. Download and extract the project folder.
2. Open `index.html` in a modern browser.

No build tools, frameworks, package installation or server are required.

For the best development experience, open the folder in Visual Studio Code and use the Live Server extension.

## How data is stored

SkillTrack uses the browser's `localStorage` with the key `skilltrack-data-v1`. Data is stored on the device/browser where the app is used. It is not a cloud database and will not automatically sync across devices.
